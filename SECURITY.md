# Security policy

This repository is an educational reference and is not a supported payroll or
tax product.

Please report vulnerabilities privately through the repository's **Security**
tab by opening a private vulnerability report. Do not include access tokens,
client secrets, tenant exports, payroll records, or other sensitive customer
data in a public issue.

For deployment guidance, see
[docs/mcp-security.md](docs/mcp-security.md).
